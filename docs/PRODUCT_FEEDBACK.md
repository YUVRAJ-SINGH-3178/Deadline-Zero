# Product feedback draft

This is a submission outline, not a claim that feedback has already been sent. Fill it with observations from the actual Alexa+ builder flow.

- **What worked well:** Record concrete observations after running the add-on in the official simulator.
- **What was difficult:** Record exact steps, errors, and time lost.
- **What Alexa+ enabled:** Describe a real voice plus screen moment witnessed in the demo.
- **Developer experience improvements:** Note which documented workflow was unclear or smooth.
- **Missing tooling:** Record whether traces, schema diagnostics, simulator controls, or logs were unavailable.
- **Faster onboarding:** Suggest improvements based on the CLI and account-linking steps actually attempted.
- **Better debugging:** Include a minimal reproducible failure and desired visibility.

No Amazon preview experience was available in the workspace during implementation, so this draft intentionally does not claim observed feedback.
