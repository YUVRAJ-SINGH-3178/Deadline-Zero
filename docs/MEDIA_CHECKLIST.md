# Media capture checklist

Capture only real UI and repository states. Do not synthesize Alexa+ screenshots.

- [ ] Alexa+ conversation showing the opening natural request.
- [ ] Inline MCP App summary and next action.
- [ ] Fullscreen plan/timeline when supported and explicitly expanded.
- [ ] Replanning response with the changed availability interval.
- [ ] What-if result alongside evidence that actual plan remains unchanged.
- [ ] GitHub repository page and commit/README state.
- [ ] Architecture view showing Alexa+, Streamable HTTP, server, planner, database, and MCP App.
- [ ] Remove account names, bearer tokens, emails, and other personal data before sharing.
- [ ] Record device, date, and whether each image came from Alexa+ simulator, device, or local preview.
