# Three-minute demo script

**0:00–0:10 — Start with the product**

Alexa: “I have three deadlines tonight and only four hours.”

Deadline Zero: “Let’s make a plan.”

**0:10–0:45 — Capture and plan**

Say: “My assignment is due at midnight, I have an exam tomorrow, and I need to study three chapters. Dinner is at eight.”

Show the tool capture and concise plan. Point out the assignment first, the dinner hold, and the study block that fits around it. Note any remaining risk honestly.

**0:45–1:15 — Visual timeline**

Show the glanceable timeline resource. The spoken summary remains understandable if the UI is hidden.

**1:15–1:50 — Interrupt and adapt**

Say: “I’m unavailable from eight to nine.”

Show the updated plan and what moved. Ask “What changed?” and summarize the replan reason and impacted work.

**1:50–2:10 — Complete work**

Say: “I finished the assignment.”

Show completion, remaining workload, and one next action.

**2:10–2:35 — What-if**

Say: “What happens if I skip studying tonight?”

Show projected impact. Return to the actual plan and demonstrate that it did not change.

**2:35–2:50 — Architecture reveal**

Show the MCP Streamable HTTP endpoint, deterministic planner, PostgreSQL adapter, and MCP App resource.

**2:50–3:00 — Close**

“Deadline Zero turns a messy request into a workable plan, then adapts that plan as life changes.”

Alexa+ access, account linking, and physical-device behavior are shown only if actually available on demo day; otherwise use the local MCP inspector/simulator path and label it as local.
